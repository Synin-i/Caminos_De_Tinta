# Caminos de Tinta

## 1. Objetivos

## 1.1. Objetivo General

Aplicar y fortalecer los conocimientos adquiridos durante el módulo de Diseño Web 1 mediante el desarrollo de un sitio web interactivo de historias ramificadas, utilizando HTML y CSS para estructurar, diseñar y organizar sus diferentes secciones. Poniendo en práctica los contenidos aprendidos en clase a través de una propuesta funcional, visualmente coherente y orientada a la interacción del usuario.

## 1.2. Objetivos Específicos

Diseñar una estructura web organizada mediante HTML, distribuyendo correctamente las distintas secciones, historias y rutas de navegación del sitio. Aplicar estilos mediante CSS para mejorar la presentación visual del proyecto, manteniendo una identidad gráfica coherente entre la página principal y las diferentes historias. Implementar un sistema de navegación interactivo que permita al usuario tomar decisiones y acceder a diferentes caminos y desenlaces dentro de cada historia. Integrar recursos multimedia, como imágenes, música, videos y narraciones, con el propósito de complementar el contenido y mejorar la experiencia del usuario.

## 2. Problemática

Actualmente, gran parte del contenido narrativo disponible en medios digitales se presenta de forma lineal, donde el usuario únicamente lee la historia sin intervenir

en su desarrollo. Esta falta de interacción puede hacer que la experiencia resulte poco dinámica y reducir el interés del lector, especialmente en entornos digitales donde se busca una participación más activa.

Frente a esta problemática, se desarrolla “Caminos de Tinta”, un sitio web de historias interactivas en el que el usuario puede tomar decisiones que modifican el rumbo de la narración y conducen a distintos desenlaces. De esta manera, la lectura deja de ser completamente pasiva y se convierte en una experiencia más participativa.

Además, el proyecto incorpora imágenes, videos, narraciones y música relacionadas con la ambientación de cada historia, con el propósito de reforzar el contexto de las escenas y generar una experiencia más inmersiva. Así, se busca combinar lectura, interacción y recursos multimedia dentro de una misma propuesta web, aplicando los conocimientos adquiridos en Diseño Web 1.

## 3. Introducción

Las historias han encontrado nuevas formas de presentarse gracias a los medios digitales. Ya no se limitan únicamente a una lectura lineal, sino que también pueden incorporar decisiones, elementos visuales, sonido y distintos recorridos narrativos que hacen que el usuario forme parte de la experiencia.

Dentro de este contexto surge “Caminos de Tinta”, un sitio web de historias interactivas compuesto por diferentes relatos, cada uno con su propia temática, ambientación y posibles desenlaces. A medida que el usuario avanza, puede elegir entre distintas opciones que modifican el rumbo de la historia y lo conducen por diferentes caminos.

Cada relato está acompañado por imágenes, videos, narraciones y música relacionada con su ambiente, lo que permite reforzar las escenas y dar mayor identidad a cada historia. De esta manera, el sitio reúne lectura, diseño e interacción en un mismo espacio, ofreciendo una experiencia más dinámica que una narración tradicional.

## 5. Conclusiones

La estructura desarrollada en HTML permitió organizar de mejor manera las distintas historias, secciones y rutas del sitio. Durante el proceso también se pudo comprobar que mantener una buena organización de carpetas y nombres es importante, ya que un error pequeño en una ruta puede hacer que una página o un recurso deje de funcionar correctamente. El uso de CSS permitió darle una identidad visual al proyecto y adaptar el diseño de cada historia de acuerdo con su temática. A lo largo del desarrollo fue necesario ajustar colores, tamaños, animaciones y distribución para lograr que el sitio se vea atractivo sin afectar la lectura ni la navegación. La navegación mediante decisiones hizo que las historias fueran más dinámicas y permitió que el usuario tenga una participación más activa. Sin embargo, trabajar con varios caminos y finales también hizo evidente que este tipo de

proyecto requiere bastante orden para evitar enlaces incorrectos o rutas mal conectadas. La integración de imágenes, videos, música y narraciones ayudó a mejorar la ambientación de las historias y a hacer la experiencia más completa. Al mismo tiempo, se observó que estos recursos aumentan considerablemente el peso del proyecto, por lo que es importante organizarlos y utilizarlos de manera adecuada.
